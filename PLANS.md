# ExecPlan Template

Each substantial feature plan must include:

## Goal

## User value

## In scope

## Non-goals

## Relevant authoritative docs

## Domain entities affected

## State transitions

## Permissions/security

## Database/migrations

## API/events/jobs/contracts

## UI/screens

## Failure states

## Acceptance criteria

## Test plan

## Observability/audit

## Rollout/rollback notes

## Assumptions

## Architecture gate required?
`no` by default; if `yes`, stop before implementation.
